ФАЙЛДАР:
- login.html: катталуу жана кирүү.
- index.html: башкы бет, статистика.
- profile.html: ар бир колдонуучунун жеке профили, упайы, рейтинги жана жооп берген суроолору.
- games.html: командалар, упайлар, оюн тарыхы, CSV экспорт.
- alphabet.html: суроолорду издөө, деңгээл/категория боюнча чыпкалоо, жооп берүү жана туура жооп үчүн 10 упай алуу.
- library.html: китепкана материалдары.
- news.html: жаңылыктар.
- admin.html: суроолорду, жаңылыктарды, материалдарды жана категорияларды башкаруу.
- style.css: жалпы дизайн жана responsive стилдер.
- app.js: localStorage, авторизация, бардык интерактивдүү функциялар.

МААНИЛҮҮ ЧЕКТӨӨ:
Бул браузерде иштеген окуу/демо прототип. localStorage жана sessionStorage чыныгы коопсуздук бербейт:
- Колдонуучу браузердин Developer Tools бөлүгүнөн маалыматтарды өзгөртө алат.
- Сырсөздөр бул демо версияда жөнөкөй текст түрүндө сакталат.
- Маалыматтар башка компьютерге автоматтык синхрондолбойт жана браузердин сактагычы тазаланса жоголушу мүмкүн.
- Катталуу/кирүү Auth Guard'ы интерфейстик тосмо гана, сервердик коопсуздук эмес.

Чыныгы интернет-платформа үчүн кийинки этапта backend (мисалы, Python FastAPI же Node.js), PostgreSQL маалымат базасы, сырсөздүн хэши, сервердик ролдор жана API кошуу зарыл. Андан кийин хостингге жайгаштырууга болот.
